## Featured Projects

### Real-Time PostgreSQL CDC Replication Pipeline

An end-to-end replication pipeline from PostgreSQL to Kafka and back to PostgreSQL using **Debezium CDC, Avro, Schema Registry, and JDBC Sink Connector**. It supports initial snapshots, near-real-time CRUD synchronization, upsert and delete semantics, persistence, and failure-recovery testing.

### Dota 2 Hero Recommendation & Match Prediction

A data-driven system combining **Apriori association rules** for hero recommendations with **XGBoost** for match-outcome prediction. The project includes automated API collection, JSON-to-CSV processing, feature engineering, and model evaluation.

### LiteraSearch

A book recommendation application developed as a Bangkit Academy capstone. It uses **collaborative filtering and cosine similarity** to recommend books and the **Haversine formula** to locate nearby libraries, served through a Flask API.
